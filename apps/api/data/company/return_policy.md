# NovaCart Return Policy

## Customer returns

- Standard return window is 30 days from delivery for unopened items.
- Defective electronics may be returned within 90 days with proof of purchase.
- Final-sale promotional items are marked clearly and are non-returnable.

## Operational impact

- Expected return rate for apparel is 12%; electronics 4%.
- Restocked returns re-enter inventory only after quality inspection.
- Refunds above $500 require fraud-check review before payout.
